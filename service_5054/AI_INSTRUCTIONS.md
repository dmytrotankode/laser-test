# Інструкція для ШІ (AI Context) - Сервіс 5054 (Лазерне обрізання шоломів)

Цей файл створено спеціально для інших моделей ШІ, щоб швидко зрозуміти архітектуру, логіку роботи та структуру пайплайну в `service_5054`.

## 1. Загальна архітектура
- **Сервер:** `server.py` (Flask). Обробляє API запити (`/api/stepXX`) та віддає статику. Запускається на порту `5054`.
- **Фронтенд:** `web/templates/index.html` та `web/static/js/main.js`. 
  - Фронтенд відповідає за послідовний виклик етапів (Step 1 - Step 8).
  - Для 3D-рендерингу використовується **Three.js** (відображення `.stl` моделей, точок, ліній лазера).
  - Управління обертанням у 3D просторі (Step 8) використовує `THREE.Quaternion` для уникнення "шарнірного замка" (gimbal lock).
- **Скрипти:** Директорія `scripts/`. Кожен етап (Step) виконується окремим Python-скриптом через `subprocess` у Flask.
- **Результати (Сесії):** Директорія `results/run_<timestamp>/`. Усі проміжні JSON-файли, фотографії, маски та логи зберігаються в ізольованій папці сесії.

## 2. Покроковий Pipeline (Етапи)

### **Step 00:** Аналіз камер
- Скрипт: `scripts/step00_analyze_cameras.py`
- Опис: (Опціональний етап) Вираховує просторове розташування камер відносно стенду.

### **Step 01:** Створення еталонної лінії (Trim & LS)
- Скрипт: `scripts/step01_create_etalon_trim.py`
- Опис: 
  - Парсить вихідний `.ls` файл з робота (отримує `original_points`).
  - Відсікає підводи/відводи лазера (отримує `contour_points`).
  - Вираховує фактичну лінію контакту на шоломі (offset) -> `contact_points`.

### **Step 02:** Суміщення 3D-моделі з точками обрізки
- Скрипт: `scripts/step02_align_3d_to_trim.py`
- Опис: Використовує алгоритм ICP (Iterative Closest Point) для ідеального суміщення CAD-моделі шолома (`helmet_ref.stl`) з хмарою лазерних точок (`contour_points`). 
  - Вираховує базові координати `tx, ty, tz` та кути Ейлера `rx, ry, rz` для **Еталонного шолома**.

### **Step 03:** Сегментація Еталона
- Скрипт: `scripts/step03_segment.py`
- Опис: Підготовка 2D масок Еталонного шолома для 3-х ракурсів (Ззаду, Зліва, Зверху) з ідеально вирівняної 3D моделі.

### **Step 04:** Аналіз Еталонних масок (Fit Masks)
- Скрипт: `scripts/step04_fit_masks.py`
- Опис: Розраховує "нульові" зміщення. Важливо: кути нахилу (`rot`) з 2D масок інвертуються для правильного мапінгу у 3D простір (правило правої руки, `rx_3d = -back.rot`, `ry_3d = -left.rot`).

### **Step 05:** Сегментація поточного шолома
- Скрипт: `scripts/step05_segment_current.py`
- Опис: Бере фотографії реального (фізичного) шолома на стенді з трьох камер. Використовує AI модель (YOLO/SAM) для виділення маски шолома (відділення від фону).

### **Step 06:** Аналіз Поточного шолома (Fit 3D)
- Скрипт: `scripts/step06_fit_3d.py`
- Опис: 
  - Використовує `cv2.estimateAffinePartial2D` для порівняння сегментованих масок із фото (Step 05) з еталонними масками (Step 04).
  - Конвертує піксельний зсув у міліметри (масштаб камери `px_to_mm`).
  - Розраховує глобальні параметри 3D зсуву поточного шолома (`global_3d`).

### **Step 07:** Порівняння та 2D-накладення
- Скрипт: `scripts/step07_compare.py`
- Опис: 
  - Вираховує `delta_3d` (різницю між Поточним і Еталонним шоломами у мм та градусах).
  - Створює візуальні оверлеї масок (Червоний — Еталон, Зелений — Поточний, Жовтий — Перетин).

### **Step 08:** 3D Візуалізація та Експорт
- Скрипт: `scripts/step08_visualize.py`
- Опис: 
  - Читає оригінальний `.ls` файл з Step 01.
  - Використовує `scipy.spatial.transform.Rotation` для конвертації `delta_3d` у Кватерніони.
  - Трансформує всі `X, Y, Z` координати у `.ls` файлі, зберігаючи при цьому всю розмітку (GP1, UF, UT, конфіги) через регулярні вирази (`re.sub`).
  - Зберігає готовий `.ls` файл (`current_helmet.ls`) для скачування та відправки на станок.
  - Фронтенд (`main.js`) також використовує кватерніони (`THREE.Quaternion().multiplyQuaternions(qDelta, qEtalon)`), щоб точно показати відхилення шолома у браузері.

## 3. Як запускати
1. Активувати віртуальне середовище (якщо використовується venv/conda).
2. Запустити сервер командою:
   ```bash
   python server.py
   ```
3. Відкрити браузер за адресою: `http://localhost:5054`
4. Натиснути **"Старт сесії"**, зробити знімки та послідовно виконати Етапи 1–8.
5. Завантажити згенерований `current_helmet.ls` наприкінці 8-го етапу.
