# Снимки сгенерированных программ для held-out вариантов

Здесь лежат `current_helmet.ls`, сгенерированные для **v6** и **v13** на каждом этапе
работы. Эти два варианта никогда не участвуют в обучении (см. `scripts/dataset.py`),
поэтому их экспорт — честный способ увидеть, что реально изменилось от этапа к этапу.

Имя файла: `<этап>_<вариант>.ls`

| Файл | Что это |
|---|---|
| `stage1_v6.ls`, `stage1_v13.ls` | Этап 1. Первая версия, которую робот вообще может загрузить: до этого экспорт для v6/v13 содержал 1 команду движения вместо 99. Модель не менялась. |
| `stage4_v6.ls`, `stage4_v13.ls` | Этап 4. Новая модель: признаки силуэта вместо 8 скаляров, обучение на парах, метки из ICP по кривой. |

Версию **до** этапа 1 при необходимости можно воспроизвести из коммита `72d0531`:

```bash
git worktree add /tmp/laser2-baseline 72d0531
```

(она будет невалидной программой — это и было проблемой)

## Как сравнивать

```bash
python tests/compare_exports.py tests/reference_exports/stage1_v6.ls results/audit_v6/current_helmet.ls
```

Скрипт печатает расстояние между траекториями (точка→кривая, мм) и отдельно —
насколько сдвинулась каждая точка. Простой `diff` тут малополезен: он покажет
изменение в каждой строке координат, но не скажет, значимо оно или нет.
