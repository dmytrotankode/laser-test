🎯 Сервіс 5056: High-Precision 3D Safe Zone Metrology

Корекція траєкторії різу за трьома монохромними знімками. Похибка вимірюється по лінії різу — куди потрапляє промінь, а не де стоїть сопло: відступ між ними на різ не впливає. На незалежній перевірці (v6, v13) — 2.6 мм проти 3.7 мм без корекції взагалі. Всередині каліброваного діапазону (v13) — 1.9 мм; за його межами (v6) — 3.4 мм, і система це позначає прапорцем out_of_range. Деталі та обмеження: PLAN.md, звіт — python scripts/evaluate.py.

Сесія: немає
Етап 1: Офлайн-профілювання 3D-моделі Офлайн
Очікування
Читання еталонного меша helmet_ref.stl: габарити, центроїд, головні осі. У розрахунку пози участі не бере — меш у власній системі координат і до координат верстата не прив'язаний. Асиметрія купола становить 8% (по головних осях 4.8%), чого замало для надійної фіксації Yaw.
Натисніть «Виконати» для генерації геометричного профілю моделі
Етап 2: Прив'язка Еталонного лазерного контуру Офлайн
Очікування
Завантаження CAD-програми TORXL_NEW_PROG.LS і точки повороту (pivot) для 6-осевої корекції. ICP тут не виконується — pivot є зашитою константою; на геометрію експорту її вибір не впливає.
Очікування виконання етапу
Етап 3: Субпіксельна сегментація монохромних фото Онлайн (Стенд)
Очікування
Виділення силуету шолома нейромережевим сегментатором (rembg). Відсікання нижніх 42% силуету (залишається верхні 58% купола) — прибирає нерівний необрізаний кевлар. Якщо rembg недоступний, крок зупиняється з помилкою: усі калібрувальні константи налаштовані саме під нього.
Очікування виконання етапу
Етап 4: Єдина 6-осева 3D оптимізація пози Онлайн (Стенд)
Очікування
Обчислення 6-осевого зміщення за профілем силуету трьох ракурсів (лінійна модель, навчена на 182 парах архівних поз). Обирається найближча архівна поза; якщо знімок виходить за межі каліброваного діапазону — з'являється попередження out_of_range.
Очікування виконання етапу
Етап 5: 3D Візуалізація та Експорт файлу для робота Фінал
Очікування
Інтерактивне 3D-середовище (Червоний Еталон, Зелений Поточний, Біла лінія лазера). Завантаження готового current_helmet.ls зі збереженням усієї службової розмітки Fanuc.
Очікування фінального етапу
