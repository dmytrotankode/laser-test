# Laser2 — лазерний різ шоломів TOR XL

Мета: за фото шолома з камер розрахувати траєкторію лазерного різу (Fanuc `.LS`),
щоб оператору не доводилось довго доводити її руками.

Карта папок станом на 2026-10-14.

## Актуальне

| Папка | Що це |
|---|---|
| **`service_2021/`** | **Робочий сервіс.** Інтерфейс оператора: набір → розмітка → розрахунок (Методи 1–4) → доведення → `.LS`. Запуск — `service_2021/start.bat`, http://localhost:2021. Документація: [service_2021/README.md](service_2021/README.md); підключення свого методу — [service_2021/methods/README.md](service_2021/methods/README.md) |
| **`laserdot_3/`** | Калібровка камер під **нову розстановку від 30.09.2026** (шолом розвернуто на 180°, камеру back перенесено): маркерні точки, скрипти калібровки, синтетичний тест, тестові набори 05.10. [laserdot_3/README.md](laserdot_3/README.md) |

**Стан на 14.10 (гілка `new-rig`):** нова калібровка `marker_2026-09-30` підключена —
нові набори рахуються з нею автоматично, старі як раніше. Для нового стенду — Метод 3
(еталон `TOR_XL_1010_1`) і Метод 4 (експеримент: + край згори + розтяг). Пакет для
перенесення на виробництво — `service_2021_update_2026-10-14.zip` (в архіві інструкція).

## Правила роботи з репозиторієм

- Фото, RAW, архіви — на диску, не в git. У git — код, розмітка, `.LS`, `.json`/`.csv`, документи.
- Калібровки й рецепти не перезаписуються: нова версія — нова папка з `meta.json`.
- Перевіряючи інтерфейс, не натискати справжнє «Зберегти» на робочих наборах.
